# Pomodoro Timer

A Pomodoro timer for the browser: 25 minutes of work, 5 minute breaks, and a longer break after every four work sessions.

Work in progress. Built with React, TypeScript and Vite.

## Run it locally

Requires Node.js 24 or newer.

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run typecheck
npm test
npm run build
```
